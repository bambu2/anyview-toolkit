# Anyview Toolkit

**半** 自动答题工具，帮助复制题目和输入答案。

## 安装

先在你的电脑中安装 Python 和 uv。

```bash
uv sync
```

## 使用

1. 登录 Anyview，进入答题页面。
2. 用浏览器检查功能 (Ctrl + Shift + C) 选中答案框, 复制元素。
3. 点击“复制题目”按钮，在倒计时内把把输入焦点放在目标位置，答案会被复制到剪贴板。
4. 粘贴题目给 AI 解答，复制 AI 答案。 (AI 对话开头提示词示例：“我给c99题目，你给答案，不用注释”)
5. 切换英文输入法！
6. 点击“输入答案”按钮，在倒计时内把把输入焦点放在目标位置。
7. 等待输入答案完毕，运行答案。

## FAQ

### Q: 为什么不用 Playwright / Selenium ?

A: 保持项目轻量，以及我不会。

### Q: 为什么不写自动登录 Anyview ?

A: 建议用 Bitwarden 之类的密码管理器来填写登录信息。

### Q: 为什么不写接入 AI API 的代码 ?

A: 不要为了 Anyview 花钱。

### Q: 为什么用 PyAutoGUI 来输入 Anyview 的答案框 ?

- Anyview 的答案框是一堆 div 和 span，我不会处理。
- 使用 Anyview 的换行机制避免换行混乱。
- 水时长。

### Q: 为什么输入时有随机延迟和随机错误 ?

- 水时长。
- 看脚本打字时不会太无聊。

### Q: 答案要求 ?

A: 只有 ASCII 字符。

### Q: 题目不会 / 答案看不懂 / 运行不通过 / AI 答案不像人写的?

A: 请自己学习，自己修改答案。
